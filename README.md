# 종목 탐색기 (조건별 리스트 + 중복 표시)

매일 아침, 코스피/코스닥을 나눠서 아래 3개 리스트를 **각각 따로** 뽑고,
2개 이상 리스트에 동시에 들어간 종목을 별도로 보여줍니다.
(3개 조건을 "동시에 모두" 만족해야 하는 방식이 아닙니다 — 그렇게 하면 거의 항상 0개가 나와서
방식을 바꿨습니다.)

1. RSI(14) 30 이하 종목 중 가장 과매도인 상위 10개
2. 전일 외국인+기관 순매수 합계 상위 30개 (네이버 증권 기준, 수량 단위)
3. 이격도(20일선)가 가장 낮은(=주가가 평균선에서 가장 많이 아래로 벌어진) 하위 10개
4. 위 세 리스트 중 **2개 이상**에 동시에 포함된 종목 (중복 표시)

> ⚠️ 이 도구는 조건에 맞는 종목을 기계적으로 찾아주는 스크리닝 도구이며,
> 매수/매도를 추천하는 것이 아닙니다. 투자 판단과 책임은 본인에게 있습니다.

> 참고: "이격도 20 이하"라는 표현은 실제로는 거의 나올 수 없는 값이라
> (정상적인 주가라면 이격도는 보통 90~110 사이), **"이격도가 가장 낮은 하위 10종목"**으로
> 해석해서 구현했습니다.

## 1. 폴더 구조

```
stock-screener/
├── main.py                # 메인 실행 스크립트 (시장별로 3개 리스트 + 중복 계산)
├── indicators.py          # RSI, 이격도 계산
├── naver_price.py         # 네이버 증권 일봉 시세 크롤링
├── naver_investor.py      # 네이버 증권 외국인/기관 순매매 크롤링
├── naver_universe.py      # 네이버 증권 시가총액 순위 크롤링 (시장별 종목 목록)
├── retry_util.py          # 요청 실패 시 재시도 헬퍼
├── notify_telegram.py     # (선택) 텔레그램 알림
├── requirements.txt
├── docs/
│   ├── index.html         # 아이폰에서 볼 모바일 웹페이지 (코스피/코스닥 탭)
│   └── results.json       # 매일 자동 갱신되는 결과 데이터
└── .github/workflows/
    └── daily-screen.yml   # 매일 자동 실행 스케줄
```

## 2. 셋업

기존에 저장소를 이미 만들어두셨다면, 이 폴더 내용 **전체로 덮어쓰기**만 하면 됩니다.
(파일들을 지우고 새로 업로드하거나, 저장소를 새로 만들어서 업로드)

1. GitHub에 새/기존 저장소 → 이 폴더 파일 전체 업로드
2. `.github/workflows/daily-screen.yml`이 안 올라갔다면, **Add file → Create new file**로
   경로를 `.github/workflows/daily-screen.yml`로 직접 입력해서 만들기 (드래그 업로드 시 숨김 폴더가
   자주 빠집니다)
3. **Settings → Pages** → Branch `main`, 폴더 `/docs` 선택 → Save
4. **Actions → Daily Stock Screening → Run workflow**
5. 완료되면 아이폰 사파리로 `https://<내계정>.github.io/<저장소이름>/` 접속 →
   공유 버튼(⬆️) → 홈 화면에 추가

## 3. 스캔 범위 및 실행 시간

- 코스피/코스닥 각각 시가총액 상위 150개씩(`TOP_N_PER_MARKET`), 총 300개를 스캔합니다.
- 종목당 여러 페이지를 크롤링해야 해서 실행에 30분~1시간 정도 걸릴 수 있습니다.
- `.github/workflows/daily-screen.yml`의 cron은 한국시간 06:30에 시작하도록 되어 있습니다.

## 4. 조건 값 조정

`main.py` 상단의 설정값으로 조정할 수 있습니다:

```python
RSI_THRESHOLD = 30       # RSI 몇 이하를 "과매도"로 볼지
RSI_TOP_N = 10            # RSI 리스트 표시 개수
NET_BUY_TOP_N = 30        # 순매수 리스트 표시 개수
DISPARITY_MA_PERIOD = 20  # 이격도 기준 이동평균 기간
DISPARITY_TOP_N = 10      # 이격도 리스트 표시 개수
TOP_N_PER_MARKET = 150    # 시장별 스캔 대상 종목 수
```
