# 종목 탐색기 (조건별 리스트 + 중복 표시 + 사후 성과 검증)

매일 아침, 코스피/코스닥을 나눠서 아래 6개 리스트를 **각각 따로** 뽑고,
"순매수를 제외한 5개 지표(RSI/이격도/거래대금/거래량급증배수/정배열)" 중
2개 이상 겹치는 종목과 3개 이상 겹치는 종목을 각각 별도로 보여줍니다.
그리고 그렇게 뽑힌 픽들이 **1주일/1개월 후 실제로 어떻게 됐는지 자동으로 추적**합니다.

1. RSI(14) 30 이하 종목 중 가장 과매도인 상위 10개
2. 전일 외국인+기관 순매수 합계 상위 10개 (네이버 증권 기준, 수량 단위)
3. 이격도(20일선)가 가장 낮은(=주가가 평균선에서 가장 많이 아래로 벌어진) 하위 10개
4. 거래대금(종가×거래량) 상위 10개
5. 거래량 급증배수(당일 거래량 ÷ 20일 평균 거래량) 상위 10개
6. 정배열(5일선 > 20일선 > 60일선) 종목 중 단기/장기 이평 격차가 가장 큰 상위 10개
7. 위 6개 중 순매수를 제외한 5개 지표 기준으로, **3개 이상** / **2개 이상** 겹치는 종목 (각각 별도 표시)

> ⚠️ 이 도구는 조건에 맞는 종목을 기계적으로 찾아주는 스크리닝 도구이며,
> 매수/매도를 추천하는 것이 아닙니다. 투자 판단과 책임은 본인에게 있습니다.

## 1. 폴더 구조

```
stock-screener/
├── main.py                 # 메인 스크리닝 스크립트 (6개 리스트 + 이중 중복 + 히스토리 기록)
├── evaluate_picks.py        # 누적된 픽을 1주일/1개월 후 실제 수익률로 검증
├── indicators.py            # RSI, 이격도, 이동평균 계산
├── naver_price.py           # 네이버 증권 일봉 시세 크롤링
├── naver_investor.py        # 네이버 증권 외국인/기관 순매매 크롤링
├── naver_universe.py        # 네이버 증권 시가총액 순위 크롤링 (시장별 종목 목록)
├── update_prices.py         # 장중 5분마다 현재가만 빠르게 갱신
├── retry_util.py            # 요청 실패 시 재시도 헬퍼
├── notify_telegram.py       # (선택) 텔레그램 알림
├── requirements.txt
├── docs/
│   ├── index.html                # 아이폰에서 볼 모바일 웹페이지
│   ├── results.json              # 매일 자동 갱신되는 오늘의 스크리닝 결과
│   ├── live.json                 # 장중 5분마다 갱신되는 현재가
│   ├── history.json              # 매일 누적되는 "2개 이상 중복" 픽 기록
│   └── performance_summary.json  # history.json을 집계한 성과 통계
└── .github/workflows/
    ├── daily-screen.yml   # 매일 자동 실행 (스크리닝 + 사후검증 + 커밋을 한 번에 처리)
    └── live-prices.yml    # 장중 5분마다 자동 실행 (현재가만)
```

## 2. 셋업

1. GitHub에 새/기존 저장소 → 이 폴더 파일 전체 업로드
2. `.github/workflows/*.yml`이 안 올라갔다면, **Add file → Create new file**로
   경로를 직접 입력해서 만들기 (드래그 업로드 시 숨김 폴더가 자주 빠집니다)
3. **Settings → Pages** → Branch `main`, 폴더 `/docs` 선택 → Save
4. **Actions → Daily Stock Screening → Run workflow**
5. 완료되면 아이폰 사파리로 `https://<내계정>.github.io/<저장소이름>/` 접속 →
   공유 버튼(⬆️) → 홈 화면에 추가

## 3. 사후 성과 검증은 어떻게 동작하나요

- `main.py`가 매일 "2개 이상 중복" 픽들을 `docs/history.json`에 날짜별로 누적 기록합니다.
- 같은 워크플로우 안에서 바로 이어서 `evaluate_picks.py`가 실행되어,
  **기록된 지 7일(1주) 또는 30일(1개월)이 지난 픽**들의 현재가를 조회해
  수익률을 계산하고 `docs/history.json`에 채워 넣습니다.
- 그 결과를 집계해 `docs/performance_summary.json`에 저장하고,
  화면 맨 위 "지난 픽 사후 성과" 카드에 평균 수익률/승률로 표시합니다.
- "1주/1개월"은 실제 거래일이 아니라 **달력 기준 날짜**로 계산합니다 (휴장일 캘린더 없이도
  안정적으로 동작하게 하기 위함).
- 데이터가 쌓이기까지 **최소 1주일 이상** 걸립니다 (그 전까지는 카드에 "데이터 쌓는 중"이라고 표시됩니다).

## 4. 스캔 범위 및 실행 시간

- 코스피/코스닥 각각 시가총액 상위 150개씩(`TOP_N_PER_MARKET`), 총 300개를 스캔합니다.
- 60일 이동평균을 계산하려고 종목당 시세를 넉넉히(70일치) 가져옵니다.
- 실행에 30분~1시간 정도 걸릴 수 있습니다. `.github/workflows/daily-screen.yml`의 cron은
  **한국시간 15:40(정규장 마감 직후)**에 시작하도록 되어 있습니다.
- **매매 타이밍 전략**: "어제 종가로 오늘 아침에 매수"하던 기존 방식은 데이터 시점과 매수 시점
  사이에 밤새 시차(약 17~18시간)가 있어, 그 사이 정보가 낡을 수 있다는 한계가 있었습니다.
  그래서 **당일 정규장 마감 직후 당일 종가로 스크리닝하고, 당일 애프터마켓(16:00~18:00
  시간외단일가)에서 매수를 검토**하는 방식으로 변경했습니다 (시차를 약 30분~2시간 반으로 단축).
  다만 애프터마켓은 정규장보다 유동성이 얇고 가격 변동폭이 당일 종가 기준 ±10%로 제한된다는 점은
  감안해야 합니다.

## 5. 장중 가격 갱신

전체 스크리닝과는 별도로, 이미 뽑힌 종목들의 **현재가/등락률**만 장중(09:00~15:45) 5분마다
`update_prices.py`가 갱신해 `docs/live.json`에 저장합니다. `docs/index.html`이 이 파일을
읽어서 화면에 표시합니다 (같은 사이트 내 파일이라 브라우저 CORS 제한이 없음).

## 6. 조건 값 조정

`main.py` 상단의 설정값으로 조정할 수 있습니다:

```python
RSI_THRESHOLD = 30           # RSI 몇 이하를 "과매도"로 볼지
RSI_TOP_N = 10
NET_BUY_TOP_N = 10
DISPARITY_MA_PERIOD = 20
DISPARITY_TOP_N = 10
TURNOVER_TOP_N = 10
VOLUME_SURGE_TOP_N = 10
VOLUME_SURGE_MA_PERIOD = 20
MA_SHORT, MA_MID, MA_LONG = 5, 20, 60   # 정배열 판단 기준 이동평균선
MA_ALIGN_TOP_N = 10
TOP_N_PER_MARKET = 150
HISTORY_MAX_ENTRIES = 200    # history.json에 보관할 최대 일수
```

중복(overlap) 판정 기준 지표는 `main.py`의 `OVERLAP_TAGS` 리스트로 조정할 수 있습니다
(현재는 순매수를 제외한 5개: rsi, disparity, turnover, volume_surge, ma_align).

`evaluate_picks.py` 상단의 `HORIZONS = {"1w": 7, "1m": 30}` 값을 바꾸면
평가 시점(며칠 후 수익률을 볼지)을 조정할 수 있습니다.

## 7. 화면 표시 관련 참고

- 하단의 순매수/이격도/거래대금/거래량급증/정배열 개별 리스트는 화면에서 숨겨져 있습니다
  (중복 판정 계산에는 계속 사용됩니다). `docs/index.html`의 `groupDefs` 배열에서 주석을
  해제하면 다시 보이게 할 수 있습니다.
- "2개 이상 / 3개 이상 중복" 리스트는 우측에 전일 대비 등락률을 크게 표시하며,
  장중에는 5분마다 실시간 등락률로 자동 갱신됩니다.
- 상단에 코스피/코스닥 지수 현재가 + 최근 추이 그래프가 표시됩니다 (장중 5분 간격 데이터 기준).
- 지수 카드에 **외인/기관/개인 시장 전체 순매매(억원)**도 함께 표시됩니다. 이 데이터는 네이버가 아닌
  한국경제(markets.hankyung.com) 페이지에서 가져오는 **실험적 기능**이라, 페이지 구조가 바뀌면
  조용히 실패하고 그 부분만 안 보일 수 있습니다 (다른 기능에는 영향 없음).
- "2개 이상 중복" 종목 중, 방향(상승/하락)을 구분하지 못하는 지표끼리만 겹친 경우
  (이격도+거래량급증 / 거래대금+거래량급증 / 이격도+RSI) 는 급락 당일에도 걸릴 수 있어서
  일반 중복 리스트에서 빼고, 화면 최하단의 "⚠️ 2개 이상 중복이지만 하락 주의" 리스트로 따로 표시합니다.
  기준 조합은 `main.py`의 `RISKY_COMBOS`에서 조정할 수 있습니다.

## 8. 백테스트 (과거 검증)

"5개 지표 중 2개 이상 중복" 조건이 실제로 상승 신호였는지, 과거 데이터로 검증할 수 있습니다.

- **Actions → Backtest (과거 검증) → Run workflow**로 수동 실행 (자동 스케줄 없음)
- `top_n`(시장당 평가 종목 수), `eval_days`(평가할 과거 거래일 수)를 입력받아 실행
- 결과는 `docs/backtest_result.json`에 저장되고, 실행 로그에도 요약이 출력됩니다:
  픽으로 뽑힌 종목들의 1주/1개월 후 평균 수익률 vs 그날 스캔된 전체 종목 평균 수익률(베이스라인) 비교
- **한계**: 종목 유니버스는 "오늘 기준" 시가총액 상위 N이라 과거 시점 실제 상위 N과 다를 수 있음(생존편향 가능),
  순매수(수급) 조건은 백테스트에서 제외(원래도 중복 판정에는 미포함이라 결과엔 영향 없음)
- 종목 수 x 평가 기간이 클수록 네이버 요청이 많아져 오래 걸리므로, 처음엔 기본값(40종목/40거래일)으로
  먼저 실행해보고 필요시 늘릴 것
